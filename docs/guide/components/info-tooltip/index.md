# InfoTooltip

The `InfoTooltip` is a custom component that uses a Bootstrap-vue-next tooltip with
an info icon. This custom component requires a title property containing the
tooltip text to display to the user.

[Read more about the Bootstrap-vue-next tooltip
component](https://bootstrap-vue-next.github.io/bootstrap-vue-next/docs/components/tooltip.html#tooltip)

## Example

```vue
<info-tooltip
  :title="Title" //should be translated
/>
```
